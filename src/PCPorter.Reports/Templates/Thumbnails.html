How to read this report Each picture comes from a record Windows or an app kept. The badge under each picture says what that record proves - for example a File Explorer thumbnail proves Windows showed the file, a browser cache entry proves a web page loaded it. Thumbnails stay after the original is deleted. A missing record does not prove something was never viewed. Times say exactly what they measure; none of them is a guaranteed viewing time.
